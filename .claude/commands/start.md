This repo uses OpenSpec. Do not plan or implement from this command.

Read `AGENTS.md` and `openspec/config.yaml`, then stop.

Ask which change to work on, and tell the user to run one of:

- `/opsx:propose <change>` — new change and its artifacts
- `/opsx:apply <change>` — implement, with the tester agent in parallel
- `/opsx:update <change>` — revise artifacts
- `/opsx:sync` — sync delta specs
- `/opsx:archive <change>` — archive after the review log is clear
- `/pr <change>` — pull request after review

Do not start implementation until they pick one.
